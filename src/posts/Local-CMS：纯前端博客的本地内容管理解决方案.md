## 项目背景与初衷

  

这是一个**纯前端（Static Site**博客项目。在传统的开发模式中，修改博客内容（如文章、友链、随想等）通常需要开发者手动编辑源代码中的 Markdown 或 JSON 文件，这对于频繁创作或非技术操作来说非常繁琐。

  

**为什么需要 Local-CMS？**

*   **无需云端服务器**：你不需要购买数据库或搭建复杂的后端环境。

*   **本地化管理**：通过在本地运行一个轻量级的 Node.js 服务，直接通过图形化界面修改项目 `src` 目录下的内容。

*   **Git 驱动部署**：在本地修改完成后，点击“一键发布”，系统会自动执行 Git 推送。结合 Vercel 或 GitHub Pages 的自动构建功能，实现“本地修改，全网同步”。

##  核心模块详解

  

管理后台划分为四大板块，涵盖了从数据分析到系统维护的所有功能：

  

### 1. 通用概览 (General)

*   **控制面板 (Dashboard)**：全站数据的“驾驶舱”。实时统计文章总数、分类标签分布

*   **知识图谱 (Knowledge Graph)**：利用 D3.js 动力导向图，将文章、分类、标签以节点形式连接。你可以清晰地看到哪些主题是你关注的重心，以及不同文章间的逻辑关联。
* ![知识图谱截图](/uploads/control.webp)

  

### 2. 内容创作 (Content)

*   **写文章 (Article Editor)**：

*   **文章管理 (Article List)**：支持对已有文章的搜索、筛选、编辑和批量操作（如批量修改分类、批量删除）。

*   **媒体库 (Media Manager)**：统一管理 `public/uploads` 下的所有资源。支持文件拖拽上传、图片压缩预览，并能审计图片是否被文章引用。
*   **标签分类 (Taxonomy Manager)**：集中管理分类和标签。当你重命名某个分类时，系统会自动更新所有关联文章的元数据。

<!-- 注意：以下图片需要您将文件复制到 public/uploads/ 目录中 -->
![内容创作界面截图](/uploads/article.webp) 

  

### 3. 数据模块 (Data Modules)

这些模块直接对应 `src/posts/dataJs/` 下的 JS 配置文件，让你像操作数据库一样管理 JSON 数据：

*   **友链管理**：管理博客的小伙伴，支持头像预览、站点描述编辑及拖拽排序。

*   **摄影相册**：管理生活瞬间。上传照片后可自动生成相册元数据，支持批量导入。

*   **语录收藏**：记录那些触动人心的金句，支持来源和分类标注。

*   **碎碎念 (Thoughts)**：即时记录灵感或日常，类似于个人微博，支持时间轴展示。

<!-- 注意：以下图片需要您将文件复制到 public/uploads/ 目录中 -->
![data模块界面截图](/uploads/friends.webp) 

  

### 4. 系统设置 (System)

*   **关于页 (About Manager)**：通过 JSON 配置化管理“关于我”页面的模块化内容（如：我是谁、技能树、坐标等）。

*   **系统维护**：

    *   **全站备份**：一键将文章、图片和配置打包为 ZIP 下载，确保数据本地双重备份。

    *   **全站恢复**：支持上传备份包快速还原博客状态。

    *   **版本历史**：查看 Git 提交日志，并在操作失误时利用“回滚”功能强制重置。

*   **一键发布**：自动化 Git 流程（add -> commit -> push），点击即可将本地修改推送到远程仓库。

##  部署与使用流程

  

### 1. 环境准备

确保你的电脑已安装：

*   [Node.js](https://nodejs.org/) (v20+)

*   [pnpm](https://pnpm.io/) (推荐) 或 npm

*   [Git](https://git-scm.com/)

  

### 2. 本地初始化

```bash

# 克隆仓库

git clone https://github.com/Dls-git/myblog.git

cd myblog

  

# 安装依赖

pnpm install

```

  

### 3. 开启创作之旅

运行以下命令，同时启动 CMS 后端和博客前端：

```bash

npm run admin

```

访问 `http://localhost:5173/cms` 即可开始管理你的内容。

  

### 4. 发布到线上

1.  在 CMS 中完成修改。

2.  点击左下角的“一键发布”。

3.  等待 Git 推送完成。

4.  如果你关联了 Vercel，它会自动检测到 Git 更新并重新构建你的网站。
